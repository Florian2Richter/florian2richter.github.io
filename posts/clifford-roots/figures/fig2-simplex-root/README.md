# Figure 2: square-root trajectories on the simplex

**Status:** PLANNED. Not built yet. In the post it currently renders as a
broken-image placeholder pointing at `figures/simplex-root-d3.svg`, wired
as `#fig-root-d3` and referenced as `@fig-root-d3`.

## What it should show

A square root `S` of the `d = 3` bistochastic completely depolarising
channel, visualised on the same triangle as Figure 1. A starting
distribution is mapped to an intermediate point by `S`, and then to the
centre by a second application of `S`. The map `S^2 = P` collapses every
starting point to the centre (the uniform distribution) in exactly two
steps. The figure should make the two-step funnelling visible: a few
sample start points, each with its short two-arrow trajectory to the
centroid.

## Suggested build

- Reuse the Figure 1 geometry (`fig1-state-space/state_space_figure.py`)
  for the triangle, so the two simplex figures register exactly. Factor
  the shared simplex-drawing into a small helper or copy the constants.
- A new `simplex_root_figure.py` generator that draws the triangle plus
  the trajectories of a chosen square-root matrix `S`.
- Output `simplex-root-d3.svg`.

## Interactive potential (optional, later)

A natural interactive: let the reader pick a `3 x 3` bistochastic matrix
(for instance as a convex combination of permutation matrices, via
sliders) and watch the trajectory of a dragged start point under
repeated application. This is one of the candidate interactive moments
for the post. Keep the same progressive-enhancement pattern as Figures 1
and 3: a static SVG baseline, with the interaction added on top and a
no-JS fallback.

## When building

Follow the conventions in `../README.md`: static SVG generated by a
Python script with geometry as top-level constants, an `interactive.qmd`
partial if interactive, a single source of truth for geometry, and an
`@fig-root-d3` reference already present in the prose. Caption is already
written in `index.qmd` (no manual "Figure N" prefix).
